# Ad-hoc learn queue

Put anything you want to understand later in this folder: a paper, an article, a report, a transcript, notes on a project task.
Nothing schedules it, so the queue never becomes a backlog.

When you are ready, ask the agent "what's in my learn queue?" and pick one, or say "explain <file>".
The agent runs an ad-hoc session on it (`skills/ad-hoc/SKILL.md`).
Do not commit copyrighted material to a public repository.
